## File Description

## Database

The queries are based on the Employee Management database.

Main tables:

* `employee`
* `department`
* `designation`
* `manager`

## How to Run

1. Open PostgreSQL or pgAdmin.
2. Create the required database.
3. Run `01_create_tables.sql`.
4. Run `02_insert_data.sql`.
5. Run `03_queries.sql`.
6. Check the query results.
